# Accura Change Index

This root file is the concise chronological index for notable Accura changes. It does not duplicate rationale. Follow each link to the owning decision or QA record.

## 2026-11-04

- Collapsed sidebar items now name themselves on hover and keyboard focus, and the Accura mark reveals the expand icon again by swapping rather than cross-fading, so an icon-only rail no longer has to be expanded to identify an entry or its toggle. [Rule](docs/rules/ui-hierarchy.md#navigation-selection) · [Decision](docs/change-log/DECISIONS.md#2026-11-04---collapsed-navigation-names-itself-on-hover-and-focus)
- Added a reusable blue information panel for persistent explanatory content and applied it to the Invitation email note with a uniform thin border and no close or collapse control. [Rule](docs/rules/ui-hierarchy.md#system-feedback) · [Decision](docs/change-log/DECISIONS.md#2026-11-04---persistent-information-uses-an-information-panel) · [QA evidence](apps/accura-prototype/design-qa.md#iteration-25--persistent-information-panel)
- Standardized Combobox options with leading content and trailing selection indicators, replaced inline Settings save notices with bottom-right success toasts, and removed the layered expand icon from collapsed navigation. [Rules](docs/rules/ui-hierarchy.md#selection-controls) · [Decision](docs/change-log/DECISIONS.md#2026-11-04---selection-indicators-trail-content-and-saves-use-toasts) · [QA evidence](apps/accura-prototype/design-qa.md#iteration-24--sidebar-combobox-and-toast-feedback)
- Strengthened table icons: icon-only buttons keep full-strength icons, row actions use the 28 px button, and every deliberate departure from library defaults is now indexed so a regenerated file cannot silently revert it. [Rules](docs/rules/ui-hierarchy.md#icons) · [Override index](docs/rules/prototype-overrides.md) · [Decision](docs/change-log/DECISIONS.md#2026-11-04---icon-weight-and-an-index-of-deliberate-overrides)
- Added an optional `endAddon` slot to the shared `ComboboxChips` primitive so multi-select comboboxes can show the dropdown chevron that `ComboboxInput` already has. [Decision](docs/change-log/DECISIONS.md#2026-11-04---comboboxchips-gains-an-optional-endaddon)
- Marked every form field as required or optional, removed helper text that repeated the label, and gave disabled inputs a recessed surface instead of dimming alone. [Rules](docs/rules/ui-hierarchy.md#form-fields) · [Decision](docs/change-log/DECISIONS.md#2026-11-04---form-fields-state-required-and-optional-explicitly)
- Added a Status column to the Settings user list with Active, Inactive, and Invitation pending, and removed the status marker from the identity cluster so every row keeps the same height. [Decision](docs/change-log/DECISIONS.md#2026-11-04---user-accounts-carry-an-explicit-three-state-status)
- Replaced free-text departments with a multi-select dropdown from a defined list, and made the email address read-only when editing an existing user. [Decision](docs/change-log/DECISIONS.md#2026-11-04---departments-are-a-controlled-list-and-email-is-fixed-after-invitation)
- Recorded the approved divergences between the built-in role detail dialog and US-005: an access matrix in place of disabled radios, no repeated description, and only the access levels the role grants. [Decision](docs/change-log/DECISIONS.md#2026-11-04---role-detail-shows-an-access-matrix-instead-of-a-locked-form)
- Replaced the Dashboard navigation gauge-like icon with Iconoir’s grid overview icon for clearer wayfinding. [QA evidence](apps/accura-prototype/design-qa.md#iteration-23--dashboard-navigation-icon)
- Added a shared Accura underline-tab component with Brand 950 selection across Settings and Dashboard, and standardized user rows as avatar, name, and email identity clusters. [Rules](docs/rules/ui-hierarchy.md#tabs) · [User identity](docs/rules/user-identity.md) · [QA evidence](apps/accura-prototype/design-qa.md#iteration-22--settings-tabs-and-user-identity)
- Separated categorical metadata from status by rendering role, module, and document-type badges as outlines while preserving filled semantic status badges. [Decision](docs/change-log/DECISIONS.md#2026-11-04---metadata-badges-use-outline-hierarchy) · [QA evidence](apps/accura-prototype/design-qa.md#iteration-20--outline-metadata-badges)
- Documented the active Brand 950 navigation, primary, and focus treatment separately from the reusable generated adapter baseline. [Decision](docs/change-log/DECISIONS.md#2026-11-04---brand-950-navigation-and-primary-treatment) · [Mapping contract](brand-assets/README.md#active-accura-prototype-mapping)
- Added Zinc 50 context headers above white Settings content bodies, keeping section actions grouped with their titles. [Decision](docs/change-log/DECISIONS.md#2026-11-04---settings-section-headers-separate-context-from-content) · [QA evidence](apps/accura-prototype/design-qa.md#iteration-21--settings-section-header-plane)
- Recorded sectioned and standalone table examples as non-binding visual references and deferred automatic table restyling until a coordinated scope is approved. [Visual reference](docs/visual-references/table-compositions.md) · [Decision](docs/change-log/DECISIONS.md#2026-11-04---card-table-visual-treatment-deferred)

- Adopted the official Accura logo assets, a 248 px → 64 px collapsible sidebar, and logo-to-expand interaction. [Decision](docs/change-log/DECISIONS.md#2026-11-03---official-logo-and-sidebar-collapse-behavior) · [QA evidence](apps/accura-prototype/design-qa.md#iteration-5--logo-crop-and-collapsed-alignment)
- Settled on a light Zinc application shell with white content surfaces and brand-led selected navigation. [Decision](docs/change-log/DECISIONS.md#2026-11-03---light-zinc-application-shell) · [QA evidence](apps/accura-prototype/design-qa.md#iteration-10--zinc-shell-with-brand-only-selection)
