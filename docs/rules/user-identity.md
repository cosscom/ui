# Accura User Identity Rules

## Standard Identity Cluster

- Whenever a person’s name is paired with an email address, present them as one identity cluster: avatar, name, then email.
- Use a real profile image when one exists. Otherwise, show a two-letter initials fallback derived from the person’s name.
- Keep the name as the primary line and the email as smaller, muted supporting text. Truncate long values without removing access to the complete email.
- Put account status beside the name when it is relevant; do not add a third text line that makes one table row taller than its peers.
- In data tables, use a 32 px avatar and a 12 px gap between the avatar and text stack. Larger detail views may increase the avatar without changing the information order.
- The avatar supplements identification and never replaces the visible name.

## Accessibility

- Treat a decorative initials avatar as hidden from assistive technology when the adjacent visible name already identifies the person.
- Preserve sufficient contrast for initials and keep status meaning available as text rather than color alone.
