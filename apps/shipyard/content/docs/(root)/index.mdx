title: Introduction

Shipyard connects a laptop to any number of development machines (a VPS, a
cloud VM, a desktop under your desk) and gives each repository on them
worktrees, terminals, agents, dev servers and automations. The agents run on
the boxes, so closing the app, sleeping the laptop or losing Wi-Fi never
stops them; the app is a view you can close and reopen at any time.

<Stage title="Get started">

```sh
curl -fsSL https://berthd.app/install | sh
```

Run that on your box, as the user your agents will run as. It installs
`berthd` with no root, starts it, installs the hooks that let agents report
their state, and prints a link: paste it into **Add a box** in the desktop
app, or into `berth pair` on your laptop.

On your Mac, [download Shipyard](https://github.com/cosscom/shipyard/releases/latest/download/Berth-macos-universal.dmg),
drag it to Applications and open it. It's signed and notarized, runs on
Apple silicon and Intel, carries the `berth` CLI, and updates itself. Every
step is in [install](/docs/getting-started/install).

</Stage>

## What it does

- **Workspaces per worktree.** Terminals, splits, and browser tabs onto each
  worktree's dev server, at private URLs like
  `http://checkout.shop.devl.localhost:1377/`.
- **Agents you can see and steer.** Claude Code, Codex and others, with a
  dashboard of who needs you, a review inbox for finished work, and
  [orchestration](/docs/guides/orchestration) (prompt, wait, check, loop, hand off)
  from the app, the CLI, or other agents.
- **Projects set up the same everywhere.** Each worktree gets its own ports,
  environment, services, hooks and flows, from the repository's
  [`.berth/config.json`](/docs/guides/project-config), a shareable
  [kit](/docs/guides/kits), or the box's own config.
- **Automations.** [Flows](/docs/guides/automations) on events, schedules or GitHub
  activity, running on the box; plus plain shell [hooks and gates](/docs/guides/hooks).
- **Plugins.** [React plugins](/docs/guides/plugins) for the app, with built-ins
  for git changes, pull requests, dev servers, box monitoring, activity and
  notes.
- **Boxes without the fuss.** Pinned mutual TLS, pairing by link, boxes on
  other tailnets, self-upgrade over Shipyard's own connection, and a
  [phone companion](/docs/guides/phone) served by each box.

## The pieces

| Piece | What it is |
| --- | --- |
| `berthd` | The daemon on each box: worktrees, sessions (tmux), services, hooks, flows, kits. |
| `berth` | The laptop CLI and background agent: connections, private URLs, the app's API. |
| `app/` | The desktop app (Tauri, React, coss ui). |
| `plugins/` | Built-in plugins, written against `packages/plugin-sdk`. |

Read [how Shipyard works](/docs/concepts/architecture) for the whole picture, or
[the security model](/docs/concepts/security) before you pair a box you care
about.
