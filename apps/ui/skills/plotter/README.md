# Plotter

Flat monochrome blueprint illustrations: precise geometry, quiet construction guides, and generous white space. Developed through the coss illustration lab.

`SKILL.md` contains the workflow; `references/` contains the art direction, feedback, implementation guidance, and visual anchors. The current coss selections are P00 (main), C03 (Particles), and E02 (404).

## Use

Copy this complete directory into your agent’s skills directory, preserving its name and relative paths. Invoke `$plotter` with the subject, intended placement, and any reference study codes.

Example: “Use $plotter to draw a flat scheduling illustration based on the Primitives and Particles references. Show two availability ranges meeting at one shared slot.”

The source lab is at `/ui/illustration-lab`, or [`../../app/illustration-lab`](../../app/illustration-lab) in the repository. The page is available by direct URL and is not linked from site navigation.
